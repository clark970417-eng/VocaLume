# Caption continuity and timing — 2026-10-28

This is an unreleased source update to version 4.6.0. It does not change audio capture waiting or the VAD thresholds.

- Within a rolling browser realtime speech segment, the first ASR result and later revisions retain all recognized sentences until a matching translation is displayed. Previously, a first result containing several sentences could start with only the last one. The cursor advances only past a delivered complete prefix; short/dependent continuations retain context.
- A current completed caption awaiting a translation can stay visible for up to 20 seconds. The previous three-second presentation cutoff discarded successful translations after the network route timed out and fell back locally. This changes how long a result may remain pending, not how long audio is collected; two in-flight requests and the latest waiting revision remain bounded. Realtime mode can still coalesce pending revisions or prioritize a newer result; it does not guarantee that every caption is delivered.
- The extension displays in-memory p50/p95/p99 timings for final source and translation delivery in desktop speech mode. The source-to-translation interval includes waiting in the translation queue. Capture-window end is not the beginning of speech or full speech-to-screen latency. Only the most recent 120 values are retained for the active session; no transcript is added to diagnostics.
- Four exact Japanese/Chinese preparation or completion replies use the adjacent source question. A changed topic, quoted text, a known different speaker, missing adjacency, or explicit user terminology still takes the ordinary route. Names continue to use the existing protections.

Focused automated extension and desktop tests cover the behavioral cases, with stubbed models and network responses. These checks do not establish a speed improvement, real-model accuracy, live-site behavior, or long-session stability. No model or paid API was run for this update. The prior interrupted 4.6.0 benchmark remains incomplete.
