# Extension 4.4.9 — task-focused popup

Date: 2026-10-25. Scope: extension popup only, compatible with installed desktop 4.4.8. Public preview installers remain 4.4.5.

## Changes

- Four persistent task tabs: reading, writing, speech and settings. A fixed 380 × 580 CSS-pixel popup keeps navigation/save feedback visible and scrolls only the content area.
- Website text opt-in remains off unless explicitly enabled. Dedicated sites show support as text instead of an ambiguous disabled, checked checkbox; generic sites retain their own opt-in.
- Exact saved language, engine, writing and caption preferences survive the redesign. Swapping reading languages also reverses synchronized writing; independent writing remains available.
- Speech action failures no longer disappear on the next health poll. Failed start/stop actions are retryable, duplicate pending actions are blocked, and draining prevents a new capture.
- Optional keys remain password fields with no stored secret placed in the input. Empty exports show guidance rather than producing an empty file.

## Automated checks

- `node --test tests/*.test.mjs`: **177 passed**, including 14 new popup-controller checks.
- The popup checks cover preserved preferences, default-off behavior, navigation without capture, keyboard focus, language swaps/sync, invalid pairs, site access/save failure, start/stop recovery, pending model status, draining, restricted tabs, zero outline/background independence, masked keys and empty exports.
- `node --check popup.js` and `git diff --check`: passed.
- The controller tests use markup IDs and simulated extension APIs. They do not stand in for rendered browser or real model checks.

## Boundaries

This verifies popup behavior and a short real capture smoke test on this Mac, not translation accuracy, all websites, all operating systems or a long thermal soak. No messages were posted. Website text translation was left off and test capture was stopped. The desktop app, translation models, native protocol and caption rendering pipeline were not changed.
