# 4.4.5 — Opera GX verification on macOS

Date: 2026-10-18 (Asia/Taipei). Apple M5 MacBook Air, 16 GB, macOS 26. Existing Opera GX profile and unpacked VocaLume extension; installed `/Applications/VocaLume.app`.

## Scope and fixes

- Reloaded the actual Opera GX extension from 4.4.1 to 4.4.4, then 4.4.5 after finding a bug. The extensions manager and popup visibly showed the new version.
- Played the existing Japanese YouTube stream replay (`NFtn4zigOws`, around 59–63 minutes), not a synthetic browser. Japanese recognition, complete Chinese captions, title translation and live-chat replay translation appeared.
- Found stale Japanese-video title translation persisting after SPA navigation to a Chinese-language video. Fixed clearing unmatched title translations and navigation invalidation.
- Added request ownership for recycled translation lines: an older reply must not overwrite/remove a newer result. Added regression coverage for restoring a removed line when the original language returns.
- In the real YouTube composer, translated `我想用皮卡丘，但是還沒抓到異色伊布。` to `ピカチュウを使いたいけど、まだ色違いのイーブイを捕まえていない。`. The result was inserted as an editable draft. Cancelled it without submitting.
- Observed live-chat `こんまほー！` rendered as `你好～!`.
- Stopped and restarted capture successfully. Both four-entry and single-pair modes accepted audio; source drafts continued updating. Visual snapshots alone do not establish that every completed single-pair translation had sufficient dwell.
- Outline disabled / width 0 remained configured; sampled rendered caption text showed no visible black outline. The user's background color was retained.

## X Tab integration

The existing profile also had another extension showing “按Tab翻譯成韓文”. Before the fix, Tab did not invoke VocaLume, although VocaLume's draft button worked. Added one delegated window-capture handler that routes only mounted VocaLume editors; it ignores unrelated editors, IME and modified Tab. After reloading the extension and X, Tab translated `謝謝你的直播，今天也辛苦了。` and inserted `配信をありがとうございます、今日もお疲れさまでした。`, with status “已放入日文，確認後自行送出。” Cleared the draft without posting. This verifies the conflict observed in this profile, not compatibility with every extension that can intercept keyboard input.

## Limits

This is a short functional test on one Mac, not a multi-hour soak or cross-device certification. The replay contained inaccurate interpretations (for example 雑誌 棚終わっていくね and チルだ). This patch fixes stale display / asynchronous lifecycle behavior; it does not retrain the model or claim all translations are accurate. Other browsers, live network failure conditions and every website are not covered by these manual observations. See the earlier 4.4.1–4.4.4 reports for sentence-order, native recovery, thermal and vocabulary tests.
