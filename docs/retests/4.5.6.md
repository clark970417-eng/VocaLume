# VocaLume 4.5.6 — name preservation and target-language guards

2026-10-26. Baseline: `fe91a0121b2795f930218248f12fcc48a03c9f89` (4.5.5). Apple M5, 16 GiB, macOS 26.4.1. Real-model comparison uses the existing HY-MT1.5-1.8B Q4_K_M model. [Inputs, outputs and timings](4.5.6-measurements.json).

## Behavior

- Preserve `まほろ`, `マホロ`, `Mahoro`, `鹿乃まほろ`, `兎田ぺこら`, `博衣こより` and `ミリプロ`, including supported attached honorifics. Do not guess kanji from pronunciation. Exact personal glossary mappings supplied to the desktop engine take precedence; source-equals-target entries can protect additional names. Unrelated words such as `まほろば` and the character `マホロア` are excluded from the short-name match.
- Mask the protected spans for one translation request, then restore their original spelling before output validation and caching. A missing marker fails explicitly instead of caching an invented name. Streaming partials hide incomplete markers. Already-Chinese and name-only inputs can bypass model inference.
- Reading adapters for YouTube, X and social sites check the sentence outside protected names. For example, `我很喜歡まほろちゃん` does not create an extra Chinese translation. The read gate is separate from writing: an explicit Chinese → Japanese draft still translates the Chinese words and preserves the name.
- Speech keeps the chosen target. If recognition already identifies Chinese while the target is Chinese, the pipeline returns that text instead of silently switching the destination to Japanese. Conservative text checks also cover mislabeled Chinese in the shared local Llama translation engine.
- Clear old translations when a virtualized message becomes Chinese. An old asynchronous social result cannot erase the newer translation occupying the same line.

Capture waiting, VAD thresholds, recognition settings, model selection and translation sampling settings are unchanged. No extra model correction pass is added.

## Measured scope

The [20-example corpus](../../extension/tests/fixtures/names-language-4.5.6.json) is authored regression material, not copied user content or a blind benchmark. Each version ran once, baseline then candidate, in isolated profiles against the same local model. Timings measure the translator method after initialization; they exclude audio, capture waiting, recognition, queueing and UI.

| Check | 4.5.5 | 4.5.6 |
| --- | ---: | ---: |
| Named sentences retaining every specified name | 7 / 11 | 11 / 11 |
| Already-Chinese inputs unchanged | 0 / 4 | 4 / 4 |
| Name-only input unchanged | 0 / 1 | 1 / 1 |
| All selected name/unchanged/pattern checks | 11 / 20 | 20 / 20 |
| Median named-sentence method time | 203 ms | 212 ms |

For `まほろは明日来ません。`, the baseline returned `瑪霍羅明天不會來了。`; the candidate returned `まほろ明天不會來了。`. All five bypass cases completed below the report's one-millisecond rounding resolution. The named-sentence sample does **not** show faster inference, and a single sequential run cannot establish a reliable latency difference.

These pattern checks are deliberately narrow. For example, the candidate still used the awkward plural `你們` in one thank-you sentence and added praise in the two-name example. Passing the name checks does not establish full semantic accuracy. The negation control produced the same valid output in both versions; its pattern was corrected to accept `無法` as well as `不能` and `沒辦法`, without editing generated output or timing.

## Remaining limits

This is a bounded known-name guard, not universal named-entity recognition. Unknown names and names misheard by speech recognition can still be wrong. Existing game terminology remains contextual; not every proper noun is forcibly frozen. Chinese/Japanese shared Han characters are ambiguous, so the detector is conservative and does not treat every Han-only phrase as Chinese. Additional desktop engines outside the shared Llama path retain their own translation behavior; extension network fallbacks use the shared name guard.

The new source/local app version is 4.5.6. Published preview installers remain 4.4.5 and are not relabelled by this update.
