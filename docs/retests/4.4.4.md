## Regressions addressed during development

- A bare destination-name hint still allowed a longer example to reverse `リザードンに進化` into Charizard being the one evolving. A matched evolution compound now preserves the destination. Positive and negative examples with Charizard, Gyarados, Sylveon, Jolteon and Flareon were checked.
- Skipping every short name contained in a longer name also skipped an independent `伊布` elsewhere in the sentence. Matching now tracks occurrences, retaining both Eevee and its named evolution when needed.
- `ダウン` must not match the beginning of `ダウンロード`.
- `コダック`, `サンダース` and `ブースター` require Pokémon context because ordinary brand/person/mechanical senses exist.

## Limits

This is an initial curated catalogue, not the full Pokédex or every shooter character, weapon and slang expression. Context detection is a per-input heuristic; a short comment without game evidence uses normal model translation. It does not read a current game from the webpage or persist game context across comments.

Terminology does not guarantee every clause's grammar or meaning. One VALORANT writing example retains awkward Japanese wording even though the requested game terms are present. These authored cases have not had native-speaker blind scoring and are not a general accuracy or latency benchmark.

No new recorded game-audio corpus was tested. Whisper hotwords, audio recognition and model weights were not changed. Plain machine-translation APIs do not accept contextual term hints; exact standalone names can still use the extension's local catalogue. The desktop override rule applies to terminology explicitly supplied in its translation context; the browser exact-name fast path uses the catalogue directly.

Opera UI reload and live-site checks remain deferred at the user's request. Source changes do not reload existing workers or page content scripts.
