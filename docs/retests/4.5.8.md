# VocaLume 4.5.8 — multilingual recovery parity

2026-10-26. Starting revision: `31f9cdd2843f1ddb0646c096a79b36c76b39834d` (4.5.7). Apple M5, 16 GiB, macOS 26.4.1. Existing HY-MT1.5-1.8B Q4_K_M model. [Authored inputs, outputs and timings](4.5.8-measurements.json).

## Scope

Japanese, Chinese, English, Korean, Spanish, French, German, Portuguese, Italian, Russian, Thai, Vietnamese, Indonesian and Arabic retain the same literal-line bypass, separate reading/speech directions, bounded native retry and manual page retry introduced in 4.5.7. This patch closes gaps in their validation and local-model instructions; it does not add a new model or more microphone waiting.

- All extension translation routes now reject empty/labelled output, missing prose and clearly incompatible scripts before a successful result is cached. A later request can recover instead of reusing bad output. Known retained names and URL/handle text do not count as translated prose.
- The production local translator now performs the same check **inside** its request-cache task, including completed incremental/SSBD/SimulMT outputs before they can be reused as final captions. A failing regression demonstrated that the old native layer accepted and cached an emoji-only answer to a spoken sentence; browser validation alone could not repair that poisoned native cache. Explicit glossary preservation is respected. Dutch and Polish, already offered by the desktop engine, retain Latin-script support too.
- Final speech translation retries once for output validation/name-marker failures or a worker exit, only if the first failure takes less than one second and the session, engine, terminology and target are still current. It reuses recognized text/context and does not run ASR again. Successful, stopped, overloaded, timed-out, slow or unclassified failures get no added retry. The one-second check limits eligibility, not completion time; a recovery attempt can add translation latency and keeps the existing worker timeout. Persistent failures stay failures.
- This includes SimulMT finals used for other languages: the single retry uses ordinary full-sentence translation instead of nesting another retry or continuing a rejected SimulMT draft. Failed final cues clear their streaming state so the next cue can proceed. Failure injection verifies both recovery and persistent failure; it is not a claim that a natural model failure occurred during the browser smoke test.
- Preserve literal-only lines in every pair. Legitimate shared words such as `OK` and Han-only Japanese such as `東京` are not rejected merely because they remain unchanged or contain no kana.
- Use Unicode script evidence for reading. Vietnamese letters such as `ạ ộ ự` are recognized outside the old limited range; Arabic digits and URL-only text are not treated as translatable words.
- Extend already-target bypasses to Korean, Russian, Arabic and Thai when all remaining letters match that script. Mixed source sentences still translate, and explicit desktop glossary entries/cancellation retain precedence. These are conservative script checks, not a general language detector.
- Chinese → other-language HY-MT1.5/2 prompts previously named the requested target but also demanded Taiwan Traditional Chinese phrasing. Remove that conflict and explicitly retain name markers that actually occur in the source. Other languages → Chinese now state the selected source language. Existing Japanese ↔ Chinese templates and non-Chinese-pair templates remain selected as before.

No VAD/silence threshold, capture interval, audio queue or model selection changes. Successful translations add no correction inference. Prompt token counts can differ; this report does not establish faster end-to-end speech latency.

## Verification

- **215 extension tests** pass. A table covers all **182 distinct supported language pairs** for script validation and literal retention. Background integration tests cover the twelve other targets, reading while speech uses a different pair, rejection of invalid output and successful retry without a poisoned cache. These are deterministic code contracts with authored/mock responses, not 182 real-model accuracy measurements.
- **832 desktop tests across 87 files** pass, including bypass/cancellation/glossary behavior, contradictory-prompt prevention, native-cache recovery and bounded final-caption retry. Pipeline integration cases cover Japanese → Chinese, Korean → English, Chinese → Japanese and English → Arabic: one ASR call, one source event, at most two translation attempts, then reuse of the valid result. SimulMT cases verify one ordinary fallback, persistent failure and successful next-cue handling. Queue-ordering mocks that returned untranslated Japanese for a Chinese target were updated to valid authored Chinese; their ordering/count/time-bound assertions remain. TypeScript, production build and lint pass; lint retains 16 existing warnings in unchanged files.
- **40 selected local-model cases** pass: 12 Japanese → other targets, 12 Chinese → other targets, 12 other sources → Chinese, and four already-target bypasses. Mixed cases retain the specified name/emoji/date/URL pieces. The four already-target cases require no inference; each mixed case has one prose inference and bypasses its literal-only lines. Inputs are authored and intentionally small.
- During validation, German `Morgen gibt es keinen Stream.` initially produced `今天早上沒有串流。`. With the explicit German-source instruction it produced `明天不會有直播。`. A Chinese → Russian case initially lost its name marker; the final prompt retained it and returned `まほろ завтра не придет.`. The Korean phrase check was corrected to accept the valid wording `停止`; the raw result was not edited to make it pass.

Model timings exclude initialization, audio, recognition, IPC and UI. The published report is the final candidate run, not a controlled speed comparison. The corpus was also used to diagnose the changes, so it is not a held-out quality benchmark or native-speaker review.

## Limits

Script validation cannot distinguish English from French/Spanish/etc., or reliably distinguish Chinese from Japanese when only shared Han characters occur. A sentence can use the expected script and still contain a mistranslation. No same-alphabet already-target bypass is inferred from script alone. Unknown names, unsupported scripts, model errors and network/device overload retain their existing limits. The final 40 cases do not establish equal quality across all pairs.

Source/local version is 4.5.8. Public preview installers remain 4.4.5 and are not relabelled by this update.
