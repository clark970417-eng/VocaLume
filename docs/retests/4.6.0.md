# VocaLume 4.6.0 — simpler settings and selectable translation APIs

2026-10-26. Baseline: `d67ca42e22ef4e1b3355ec580c87986f36f53dc5` (4.5.9). Local installation: Apple M5, macOS, Opera GX and the existing local speech/translation models.

## Changes and task paths

| Task | Extension | Desktop App |
| --- | --- | --- |
| Choose languages | Text translation combines reading and reply directions; a synchronized reply shows its reverse direction without duplicate selectors | Translate opens directly to language and audio source |
| Start or stop captions | Speech captions; controls stay below the scrolling area, and active Stop remains available on other tabs | Start/Stop and Save stay below every settings section |
| Adjust subtitles | Subtitle/settings tab directly exposes font size, colors and outline; speech tab also links here | Subtitles directly exposes appearance controls |
| Choose engines | Speech page has a descriptive translation-method group | Models directly exposes recognition, translation and glossary |
| Configure an API | Subtitle/settings → Network translation service → provider, model and key | Desktop speech continues using its existing App engine |

Common language, caption-mode and appearance tasks require at most one section change. Optional settings remain grouped by purpose. The desktop sections preserve unsaved values when switching; both interfaces support keyboard section navigation. Old extension reading/writing tab preferences open the combined text page. Navigation does not turn on website translation or start audio capture.

## API behavior

The extension offers OpenAI, Google Gemini, Anthropic Claude, NVIDIA, OpenRouter and custom OpenAI-compatible Chat Completions services. Provider selection changes the actual translation route for website text, translated drafts and browser-mode captions. Desktop speech keeps its selected App engine. Curated unambiguous phrases and literal-only content can still use local fast paths.

- Each provider keeps its own model and credential. Existing NVIDIA/OpenRouter credentials remain usable; an empty key field preserves a saved key and explicit removal clears it. Saved keys are not filled back into the form.
- Built-in providers have fixed hosts. A changed custom endpoint requires re-entering or clearing its existing key. HTTPS is required except for exact loopback hosts; credentials in URLs, queries/fragments and redirects are rejected.
- Saving requests the selected host's optional permission. Invalid forms or denied permissions leave the previous configuration intact. Merely selecting a provider does not apply it.
- The connection-test button uses one fixed authored Japanese sentence, only from the extension popup. It does not send current page content. A selected API's failure remains visible instead of silently routing text to another provider.
- Requests have a ten-second deadline, support cancellation, and reject truncated, refused or empty output. Provider/model/configuration changes separate cached results. Keys are excluded from cache identities and error messages.
- Custom services must implement the supported Chat Completions protocol. Azure deployment URLs, special authentication schemes and every model-specific parameter combination are not covered.

Protocol contracts were checked against the official [OpenAI Chat Completions reference](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create), [Gemini generateContent reference](https://ai.google.dev/api/generate-content), [Claude Messages reference](https://platform.claude.com/docs/en/api/messages/create) and [Claude API versioning](https://platform.claude.com/docs/en/api/versioning). Users enter a model ID available to their own account; new OpenAI/Gemini/Claude profiles do not assume a particular model entitlement.

## Scope and limits

This update changes navigation and optional API routing; it adds no audio capture wait, VAD threshold, recognition pass or model download. It does not establish better translation quality or lower end-to-end speech latency for any cloud provider. Provider availability, account permissions, quotas and model speed need verification with the user's own API account using the saved-setting test button.

Source and this Mac's App/extension are 4.6.0. Public preview installers remain 4.4.5. Ad-hoc local signing is not Apple Developer ID signing or notarization. See the [quick-start guide](../extension-guide.md) for usage.
