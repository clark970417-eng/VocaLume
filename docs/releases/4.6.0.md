# VocaLume 4.6.0 Beta

多語字幕、網站閱讀與留言翻譯，現在用更集中、容易找到設定的介面操作。這是從公開版 4.4.5 升級的預覽版本。

## 下載與開始使用

| 電腦 | 在下方 Assets 下載 |
| --- | --- |
| Mac Apple M 系列 | `VocaLume-4.6.0-arm64.dmg` |
| Mac Intel | `VocaLume-4.6.0.dmg` |
| Windows x64 | `VocaLume.Setup.4.6.0.exe` |
| Linux x64（實驗性） | `VocaLume-4.6.0.AppImage` |
| 瀏覽器擴充功能 | `vocalume-extension.zip` |

[新用戶使用手冊](https://github.com/clark970417-eng/VocaLume/blob/main/docs/user-guide.md) · [English quick start](https://github.com/clark970417-eng/VocaLume/blob/main/docs/README.en.md)

Mac 本機瀏覽器字幕需依手冊註冊連接程式；所需安裝器已放入 Extension ZIP。Windows / Linux 的獨立 App 與瀏覽器模式可分別使用，目前沒有相同的本機連接安裝流程。

## 本版更新

- App 以 Translate / Subtitles / Models / More 集中常用設定；Extension 的文字、語音、外觀設定各有入口，收音中的停止鍵持續可見。
- 可選 Gemini、OpenAI、Claude、NVIDIA、OpenRouter 或自訂相容 API，各自儲存模型與金鑰。API 為選用；明確選擇的服務失敗時會顯示原因。
- 改善換氣與長句分段、極短句的前文使用、名字與遊戲詞彙保留，以及多語翻譯失敗後的恢復。保留單組與四組字幕的原文／譯文配對。
- 新增 28 個固定日中雙向音訊案例與 8 組前文案例，涵蓋快語速、口語、名字、合成遊戲音效與多人情境；提供人工審查表、尾端延遲與長時間測試流程。
- 精簡首頁，補上下載、使用、更新與疑難排解；歷史報告集中保留，公開下載不包含開發測試資料。

## 驗證與限制

- 既有 4.6.0 程式檢查與 Mac / Windows / Linux CI 已通過；安裝版 Mac App 與 Opera GX 字幕曾完成實際收音檢查。[操作驗證](https://github.com/clark970417-eng/VocaLume/blob/main/docs/retests/4.6.0.md)
- 品質評估的實際結果與未完成項目列在[品質記錄](https://github.com/clark970417-eng/VocaLume/blob/main/docs/quality/README.md)。合成音訊、字串檢查與 CI 不等於雙語人工審查或跨裝置實機驗收。
- Gemini 等 API 已做格式與本機模擬檢查，本次沒有使用真實付費金鑰呼叫。帳戶權限、額度與模型可用性需由使用者的實際設定決定。
- 安裝檔尚未取得正式簽章／公證；本版仍為 Beta，沒有宣稱可商售品質已全部驗收完成。

## 更新注意

停止收音並關閉 App 後再安裝。Extension 解壓覆蓋原資料夾，重新載入，再重新整理影片頁；保留原 ID 與模型。不要刪除已載入的 Extension 資料夾。

`SHA256SUMS.txt` 可核對每個下載檔與 `release-manifest.json`；後者記錄確切來源 commit 與建置工作。[隱私與回報](https://github.com/clark970417-eng/VocaLume/blob/main/PRIVACY.md)
