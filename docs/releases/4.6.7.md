# VocaLume 4.6.7

- 本機翻譯改用 PLaMo 3 Translate 0.8B。桌面版升級時會把舊的 HY-MT1.5 翻譯設定轉到 PLaMo。
- YouTube 新增手動 CC 模式。字幕逐字更新時會合併重複片段，跳轉或切換影片時會清除舊字幕。
- 目前播放的字幕優先翻譯。可為 YouTube 頻道個別設定主播名稱、遊戲用語和直播詞彙。
- OBS 可用瀏覽器來源顯示字幕，也可沿用文字檔。Windows 另支援直接推送至 OBS 文字來源。
- 修正日翻繁中的「スパチャ」用詞與字幕尾端亂碼。OBS 字幕可以只顯示譯文，也可顯示原文與譯文。
- macOS 提供 Apple Silicon 和 Intel 安裝檔。Apple Silicon 版本隨附 Haas-ja Q8_0。Windows 提供 x64 安裝程式。

## 下載

- Windows x64 選 VocaLume.Setup.4.6.7.exe
- Mac Apple Silicon 選 VocaLume-4.6.7-arm64.dmg
- Mac Intel 選 VocaLume-4.6.7.dmg
- Windows 擴充功能選 vocalume-extension-windows.zip，Mac 選 vocalume-extension.zip

解壓縮擴充功能後，依照瀏覽器的 [安裝步驟](https://github.com/clark970417-eng/VocaLume/blob/b72cdec6389fee9ce7933c83cc85c31d25629515/docs/installation.md#browser-extension) 載入。

這是公開測試版，安裝檔未做開發者簽章。macOS 與 Windows 可能會顯示系統安全提示。請用 `SHA256SUMS.txt` 核對下載檔案。
