## Windows 測試版

1. 在下方 **Assets** 下載並執行 `VocaLume.Setup.4.6.5.exe`，再依 App 提示完成首次設定。
2. 要測瀏覽器功能，下載 `vocalume-extension.zip`，解壓縮後依[安裝教學](https://github.com/clark970417-eng/VocaLume/blob/main/docs/installation.md)載入 Chrome 或 Opera GX。Windows 擴充功能使用瀏覽器模式，桌面 App 可獨立跑本機翻譯。
3. 測試 YouTube／Twitch 主播聊天室翻譯、語音字幕與位置設定。若遇到問題，請附上 Windows 版本、顯示卡與重現步驟。[回報問題](https://github.com/clark970417-eng/VocaLume/issues/new/choose)

### 選測 Haas-ja 日文語音辨識

下載 [Windows x64 Vulkan 執行檔](https://github.com/nyosegawa/speech.cpp/releases/download/v0.10.1/speech-0.10.1-windows-x64-vulkan.zip) 和 [Q8_0 模型](https://huggingface.co/sakasegawa/Haas-ja-v1.0-GGUF/resolve/main/Haas-616M-ja-v1.0-Q8_0.gguf)。將解壓縮後的執行檔及 DLL 和模型放入 `%LOCALAPPDATA%\VocaLume\haas-ja`，再重開桌面 App。在日文語音辨識選擇 Haas-ja，可切換是否使用限定片語提示。Windows Vulkan 辨識仍待實機驗證。

Windows testers can try YouTube and Twitch streamer chat translation, caption placement, and the optional Haas-ja Japanese speech recognition engine. Haas-ja requires the separate runtime and model listed above and runs in the desktop app.
