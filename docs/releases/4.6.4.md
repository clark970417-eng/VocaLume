## Windows x64 下載與測試

1. 往下到 **Assets**，下載並執行 `VocaLume.Setup.4.6.4.exe`。首次開啟請依畫面提示完成模型下載。
2. 要測瀏覽器功能，再下載 `vocalume-extension.zip`，解壓縮並依[安裝教學](https://github.com/clark970417-eng/VocaLume/blob/main/docs/installation.md)載入 Chrome 或 Opera GX。Windows 的擴充功能請使用瀏覽器模式。它需要 WebGPU，並使用線上文字翻譯。桌面 App 可獨立執行本機翻譯。
3. 這是未簽署的測試版。若 SmartScreen 顯示提示，可先用 `SHA256SUMS.txt` 核對檔案。

## 本版更新

- **OBS 即時字幕**。在桌面 App 開啟 OBS 字幕輸出，在 OBS 新增文字來源並選擇 App 顯示的字幕檔。可輸出譯文或雙語。
- **翻譯紀錄編輯器**。翻譯音訊或影片後，可在 App 檢視與修改字幕並匯出文字。
- **監看資料夾**。選擇資料夾後，可讓 App 依序翻譯新增的音訊與影片。
- **DeepFilterNet3 麥克風降噪**。安裝包已附上降噪所需檔案。可在音訊設定開啟，並用同一段帶噪音的語音比較開關效果。
- 修正桌面收音後無法送出正式譯文的問題。

上述功能已在 Mac 本機驗收，這版邀請 Windows 使用者實測。請依序試首次模型下載、麥克風及電腦聲音、語音字幕、檔案翻譯與編輯匯出、資料夾監看、OBS 字幕更新，以及擴充功能讀取與回覆翻譯。若遇到問題，請提供 Windows 版本、CPU／GPU、操作步驟和錯誤畫面。[回報問題](https://github.com/clark970417-eng/VocaLume/issues/new/choose)
