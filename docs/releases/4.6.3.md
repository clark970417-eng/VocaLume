# VocaLume 4.6.3 — 下載與安裝 / Download & install

第一次使用？請先看 [圖文與影片安裝教學](https://github.com/clark970417-eng/VocaLume/blob/main/docs/user-guide.md)。下載不需要登入 GitHub。

1. 下載適合電腦的 App：Apple 晶片 Mac 選 `VocaLume-4.6.3-arm64.dmg`；Intel Mac 選 `VocaLume-4.6.3.dmg`；Windows 選 `VocaLume.Setup.4.6.3.exe`；Linux 選 `VocaLume-4.6.3.AppImage`。
2. 要在瀏覽器使用時，再下載 `vocalume-extension.zip`，解壓後依教學載入 Chrome／Opera GX。只使用桌面 App 不需要 Extension。
3. 首次開啟 App 需下載模型。Mac 網頁本機字幕還要完成教學中的 App 連接步驟；Windows／Linux 的瀏覽器模式限制也請先查看教學。

下方「Assets」是安裝檔清單。`Source code` 是原始碼，並非安裝程式。
