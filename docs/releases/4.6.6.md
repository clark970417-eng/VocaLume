## Windows x64 測試

下載下方 Assets 的 **VocaLume.Setup.4.6.6.exe**。若也要測打字翻譯，另外下載 **vocalume-extension.zip**，解壓縮後在 Chrome 或 Opera GX 載入。[安裝教學](https://github.com/clark970417-eng/VocaLume/blob/main/docs/installation.md)

- 桌面 App 選日文語音時使用 Haas-ja Q8_0，可關閉限定片語提示。Haas-ja 需要另外安裝執行檔與模型。[Haas-ja 安裝步驟](https://github.com/clark970417-eng/VocaLume/blob/main/docs/releases/4.6.5.md#選測-haas-ja-日文語音辨識)
- 選中文、英文或韓文語音時使用 SenseVoice Small。其他語言沿用相容引擎。
- 擴充功能的打字翻譯套用內建詞彙，保留原文中的 `ww`。Windows 擴充功能的瀏覽器語音模式與桌面 App 的引擎分開。

請在 Windows 實機測試首次設定、收音、字幕和打字翻譯。[回報問題](https://github.com/clark970417-eng/VocaLume/issues/new/choose)

Windows testers can download the x64 installer and optional browser extension below. Try Japanese speech with Haas-ja, Chinese, English or Korean speech with SenseVoice, and typed translations containing game terms or `ww`.
