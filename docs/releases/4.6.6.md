# VocaLume 4.6.6 公開測試版

Windows 與 Mac 的更新已整合到同一版本。先下載適合你電腦的 App。如果要在瀏覽器看字幕、翻譯聊天室或翻譯回覆草稿，再安裝同版擴充功能。

## 與上一個正式發布的 4.6.0 相比

- 新增 OBS 即時字幕、影音匯入與資料夾監看、翻譯紀錄編輯與匯出，以及支援裝置上的 DeepFilterNet3 麥克風降噪。
- 新增繁中、簡中、日文和韓文介面與五語官網。下載與安裝說明統一由 GitHub 提供。
- 更新 Electron 打包依賴並加入安全稽核。下載與原始碼使用條件請參閱儲存庫的授權說明。

### Windows

- 修正部分電腦首次啟動、模型下載中斷、系統收音和瀏覽器連接的問題。GPU 偵測和語音辨識在獨立程序執行，並限制推論執行緒，減少模型啟動時卡住整個介面的機會。
- 新增 Chrome／Edge 與桌面 App 的本機連接。收音來源和語言相容時，瀏覽器可顯示 App 已產生的字幕，減少重複收音。
- 自動翻譯優先選用較小的 HY-MT1.5 1.8B，仍可手動選擇 7B。缺少 Haas-ja 時會選用相容的日語辨識引擎。
- 新增系統聲音輸入裝置選擇、系統朗讀語音和輸出裝置設定，並支援講者辨識及笑聲分析。
- OBS 可透過本機 WebSocket 將譯文推送到指定的「文字（GDI+）」來源，也可繼續用字幕檔。

### Mac

- 依 Apple 晶片和 Intel 分開精簡安裝包，清除各架構不會用到的資源。設定只顯示有對應支援的引擎和功能，並保留可用的辨識備援。
- Chrome／Opera GX 可使用 App 內附的本機連接工具。從舊版 Python 連接升級時，請用新版擴充功能的 ID 重新註冊。
- 減少重複辨識和字幕畫面更新。低耗電模式、記憶體壓力或過熱時會減少選用的背景工作，讓正式字幕優先。維持原有的收音等待設定。

### 桌面 App 與字幕

- 新增日文和韓文介面，並整理繁中、簡中和英文。App、擴充功能與官網可同步介面語言，自動模式可依地區或系統／瀏覽器偏好選擇。
- 依用途分開即時翻譯、文字翻譯、檔案翻譯、字幕與 OBS、模型和進階設定。新增文字翻譯頁，可貼上其他軟體的訊息、翻譯後複製。
- 擴充影音匯入和資料夾監看。可搜尋、編輯和匯出帶時間碼的字幕，也能取消匯入或複查辨識不確定的片段。
- 新增「滑鼠靠近時隱藏字幕」。游標移到字幕旁時可操作底下的按鈕，離開後字幕恢復。可拖曳字幕並記住位置，另有低負載的顯示選項。
- Windows 和 Mac 可在「即時翻譯」或「字幕與 OBS」選擇單組或四組完整字幕。兩頁共用設定，浮動字幕與 OBS 都會套用。瀏覽器直播字幕可在擴充功能獨立切換。
- OBS 會記住字幕設定，支援只在 OBS 顯示、長字幕換行、略過重複寫入及停止後清空。Mac 與 Linux 使用字幕檔。

### 擴充功能、翻譯品質與官網

- YouTube 有可用的原始字幕時可直接翻譯，沒有可靠字幕時可改用語音辨識。YouTube 和 Twitch 直播聊天室可自動翻譯外語留言，已是目標語的留言會保留。
- 修正 Bilibili 直播彈幕「中 → 日」草稿回填，改善 Discord、Twitch、X 等網站的草稿相容性。網站若拒絕回填，仍可複製譯文。訊息由你自行送出。
- 完整字幕優先處理並依說話順序更新。暫時逾時的完整字幕可有限次重試。
- 改善短句和跨句語境、專有名詞、日期與數量、否定句和繁中用語。暫時翻譯失敗時有限次重試，並可手動重試。聊天室只掃描新增或改動的內容。
- 官網五種語言補上 OBS 主播示範與安裝說明，改善手機上的影片播放。
- Linux 提供 x64 AppImage 測試版。桌面 App 可獨立使用，瀏覽器端可選瀏覽器模式。Linux 的本機 App 連接未隨這版提供。

## 雙直播字幕實驗版（Apple Silicon Mac）

用兩個獨立的 Chrome 個人資料，各自收音與翻譯。測試時，兩個分頁播放不同的日文音訊，都顯示了日文原文和繁中譯文。停止一路後，另一路仍能翻譯新的一句。

實驗包內有通用 4.6.6 擴充功能和中英文操作指南。語音辨識在本機執行，文字使用網路翻譯服務。舊版實驗包的短測首筆完整譯文約等 13–39 秒，這不是本次重打包的量測值。同一個人資料內的雙路、長時間使用和三路以上仍待驗證。

## English summary

4.6.6 combines the Windows and Mac work in one public beta. It adds Windows browser-to-app integration and OBS WebSocket caption output, slimmer Mac downloads, synchronized interface languages, improved captions and chat drafts, and a more complete file-translation workflow. Choose the installer for your operating system above, then add the matching extension if you use VocaLume in a browser.

The optional dual-stream lab passed a short Japanese-to-Traditional-Chinese test on Apple Silicon using two separate Chrome profiles. The lab ZIP includes setup instructions.
