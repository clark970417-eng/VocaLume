# VocaLume 4.6.1｜預覽更新 / Preview update

免費本機翻譯直播與聊天。這次先提供 **Mac Apple 晶片版＋Chrome／Opera GX 擴充功能**；Windows、Intel Mac、Linux 的 4.6.1 尚未通過重新建置，請勿將舊版視為已更新。

## 下載與開始使用

| 需要的檔案 | 下載 |
| --- | --- |
| Mac Apple 晶片 App（M1–M5 等） | [下載 App](https://github.com/clark970417-eng/VocaLume/releases/download/beta-v4.6.1/VocaLume-4.6.1-arm64.dmg) |
| Chrome／Opera GX Extension | [下載擴充功能](https://github.com/clark970417-eng/VocaLume/releases/download/beta-v4.6.1/vocalume-extension.zip) |

**下載不需要 GitHub 帳號。** 網頁本機字幕需安裝兩個檔案，並完成一次性 App 連接；只用桌面 App 時不必安裝 Extension。

1. 開啟 DMG，將 App 拖進「應用程式」，啟動並下載模型。
2. 解壓 Extension ZIP 到固定資料夾。在 Chrome 開啟 `chrome://extensions`；Opera GX 使用 `opera://extensions`。開啟開發人員模式 → 載入未封裝擴充功能 → 選擇含 `manifest.json` 的資料夾。
3. 按[完整安裝說明](https://github.com/clark970417-eng/VocaLume/blob/main/docs/installation.md#connect-the-mac-app)完成 Python 3 與 App 連接，然後重新載入擴充功能、重新整理影片頁。從 Extension 開始字幕，勿同時從 App 重複收音。

[中文安裝教學影片](https://github.com/clark970417-eng/VocaLume/releases/download/beta-v4.6.1/VocaLume-Chrome-Setup-Guide-Final-ZH.mp4) · [中文使用手冊](https://github.com/clark970417-eng/VocaLume/blob/main/docs/user-guide.md) · [English quick start](https://github.com/clark970417-eng/VocaLume#readme)

教學以 4.6.0 錄製，部分畫面可能不同；影片未演示完整的 App 連接、模型下載與首次收音，請接著完成文字教學。

## 這次補上什麼？

- App 與 Extension 的英文、繁體中文及簡體中文介面。
- 寶可夢／寶可夢卡等明確日文用語的保護，以及安裝文件與下載連結修正。
- 修補上一輪發現的執行依賴問題，補上建置安全檢查。
- GitHub 補存五語網站、手機版排版、下載說明及教學影片。

## 更新與限制

先停止收音並關閉 App，再安裝新版。Extension 更新原固定資料夾後按重新載入，再重新整理網頁；不必刪模型。

這是公開預覽版，未有 Apple Developer ID 簽章／公證。首次使用需下載模型；速度取決於電腦，翻譯可能出錯。Windows／Intel Mac／Linux 的新版尚未提供，舊版見 [4.6.0](https://github.com/clark970417-eng/VocaLume/releases/tag/beta-v4.6.0)。

發布前既有驗證：858 項 App 測試、296 項 Extension 測試、型別檢查、正式編譯、Mac 套件資源與臨時簽章、DMG 完整性；本次重新執行 GitHub Extension 檢查通過。未新增模型、長時間收音或跨裝置準確度實測。

**最新安全檢查狀態：** 11/4 重新建置發現 minimatch 的 moderate 開發工具依賴警示，安全閘門阻擋完整跨平台發布。這不是新的執行引擎驗證；此頁提供此前完成驗證的 Mac 預覽檔，不能宣稱目前完整依賴稽核為零。[建置紀錄](https://github.com/clark970417-eng/VocaLume/actions/runs/41744848331)
