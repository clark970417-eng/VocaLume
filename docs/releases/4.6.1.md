# VocaLume 4.6.1 — release candidate

Release assets are available only after the release workflow completes; source changes alone do not update installed apps.

- Updates vulnerable runtime and build dependencies. Sharp 0.35.5 and simple-git 4.0.2 are explicitly overridden until upstream dependency ranges accept patched versions.
- Includes English, Traditional Chinese and Simplified Chinese interface options.
- Includes the pending Pokémon terminology protection fix and corrected installation documentation.
- Fixes release-package regression coverage for the Simplified Chinese interface module.

Validation: App unit tests and TypeScript checks; extension unit tests; production build; package provenance verification. No new model accuracy, long-session capture, Windows or Intel hardware qualification is claimed.

The locally built Apple Silicon installer remains an unsigned/not-notarized preview. Other platform packages still require CI builds. The complete cross-platform asset set must pass the release gate before publication.
