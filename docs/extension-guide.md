# VocaLume 擴充功能快速上手

在想使用的網站上，點瀏覽器工具列的 VocaLume 圖示。三個分頁集中常用操作，會記住上次使用的分頁：

- **文字翻譯**：閱讀貼文、聊天室和翻譯自己的留言，語言在同一頁調整。
- **語音字幕**：選語言、單組或四組字幕，按開始。
- **字幕與設定**：直接調字體大小、顏色和描邊；較少用的服務設定可再展開。

## 文字翻譯：讀文字

1. 選擇「原文語言」與「翻譯成」，例如日文 → 繁體中文。
2. 開啟「網站文字翻譯」。預設關閉，單純看到外語不會自行開啟。
3. 回到頁面查看譯文。YouTube、X、Twitch、Discord 等支援網站使用各自的文字規則；一般網站還需開啟「允許此網站翻譯」。

兩種語言中間的 ⇄ 可交換方向。來源與目標相同時不會儲存，底部會提示修改。

## 文字翻譯：寫留言

1. 開啟「網站文字翻譯」，並確認目前網站已允許。
2. 「翻譯我的留言」會顯示目前方向。開啟「自動反向回覆」時，閱讀日文 → 中文，留言便是中文 → 日文；關閉後才展開「我用」與「翻譯成」，可以獨立選擇。
3. 在網站留言框輸入文字，點留言框旁的翻譯按鈕；X 也支援 Tab。
4. 確認譯文，再自行送出。VocaLume 不會替你發布訊息。

中翻日時，可展開「中翻日的語氣與品質」選擇自然、直播留言或禮貌語氣。快速模式共用字幕模型；高品質模式可能需要更多記憶體和載入時間。

## 語音字幕

1. 在瀏覽器播放影片或直播。
2. 選擇「聽到的語言」與「翻譯成」。
3. 選擇單組或四組字幕；通常可以沿用原本的翻譯方式。要更換引擎時，展開「翻譯方式」。桌面模式需要已安裝 VocaLume；瀏覽器模式首次需要下載辨識模型，文字翻譯需要網路。
4. 按底部的「開始語音字幕」。狀態會顯示載入、收音、辨識或翻譯情況。關閉彈出視窗不會停止字幕。
5. 按底部的「停止收音」結束；收音中切換到其他設定頁，停止鍵仍會留在底部。已記錄的內容仍會完成翻譯；完成後可再次開始。

語音字幕與網站文字開關互相獨立。字幕記錄可在此分頁展開、匯出，或重試失敗的翻譯。

桌面模式會先顯示原文，再逐段補上譯文。已收到約 2.5 秒的內容後，可在明顯換氣時送出一段；超過 4 秒時也會利用較短的停頓。連續說話通常最多約 8 秒便送出一段，避免累積成整段未翻譯文字。這是收音分段上限，實際出現譯文還需要辨識與翻譯時間。短暫換氣、已辨識出的未完句會保留較長等待；連續說話超過上限仍可能在句中分段。

字幕顯示「翻譯未完成」時，四組模式的原文仍會留在記錄裡，可展開「字幕記錄」按「重試失敗翻譯」。單組模式會保留目前句子，等譯文完成並顯示後才換下一句；若該句失敗，會先顯示失敗提示再繼續。

## 字幕與設定

- **字幕外觀**可預覽原文與譯文的顏色、大小、描邊和背景。開啟「滑鼠靠近時隱藏字幕」後，移到字幕上即可操作後方網頁，移開便會恢復顯示。按住 Alt／Option 仍可拖曳或調整字幕大小。
- **單組／四組字幕**：位於「語音字幕」頁。單組等完整譯文顯示後再換句，四組保留依序翻譯的記錄。模式在下次開始時生效。
- **網路翻譯服務**：選用。選擇 OpenAI、Gemini、Claude、NVIDIA、OpenRouter 或自訂相容 API；只顯示該服務的模型與金鑰欄位。詳見下方步驟。
- **連線與執行資訊**：遇到問題時，可查看處理狀態。

一般設定會自動儲存，底部會顯示結果；服務金鑰需按「儲存翻譯服務」。可用左右方向鍵切換功能分頁，Home / End 移到第一／最後一頁。

## 使用自己的 API

1. 進入「字幕與設定」→ 展開「網路翻譯服務」。
2. 選擇服務，填入該帳戶可使用的**模型 ID** 和 API Key。自訂服務需提供支援 Chat Completions 的 Base URL，例如服務的 `https://…/v1`；本機服務可使用 `http://localhost:連接埠/v1`，並可不填金鑰。網站的聊天訂閱與 API 額度可能不同，請使用 API 平台提供的金鑰。
3. 按「儲存服務」。若瀏覽器詢問是否允許連線，確認是你選擇的服務後允許；拒絕時原設定不會改變。
4. 按「測試已儲存設定」。只會送出固定示範句，使用少量 API 額度；不會把目前網頁內容拿去測試。

服務與模型分開記住，已儲存的金鑰不會填回畫面，留空可保留。需要刪除時勾選「移除此服務已儲存的金鑰」再儲存。更改自訂 API 網址後，需要重新輸入金鑰，避免把舊金鑰送到另一個網址。

**套用範圍**：明確選擇的 API 用於網站文字、自己的留言，以及「瀏覽器」模式的字幕翻譯。明確短語和純符號仍可直接在本機處理；API 失敗會顯示錯誤，不會悄悄轉給另一家服務。桌面語音仍使用 App 中選擇的引擎。選回「沿用目前方式（本機／自動）」可恢復原流程。切換不會自動開啟網站文字翻譯。

只有格式相容且帳戶有權使用的模型才能連線；Azure 部署、自訂特殊驗證或非 Chat Completions 協定不一定相容。金鑰存在目前瀏覽器的本機擴充功能儲存區，未新增雲端同步。

## 桌面 App：常用設定直接進入

- **即時翻譯**可選擇說話語言、翻譯語言與聲音來源。指定兩種語言後，可用 ⇄ 交換方向。
- **文字翻譯**可翻譯貼上的聊天訊息或草稿。
- **檔案翻譯**可匯入影音、監看資料夾，以及編輯或匯出字幕。
- **字幕與 OBS**可調整桌面字幕外觀與位置，並設定 OBS 字幕輸出。瀏覽器字幕請在擴充功能的「字幕與設定」調整。
- **模型**可調整辨識與翻譯引擎、品質及詞彙。
- **進階設定**可調整語氣與笑聲、語音播放、快捷鍵及支援選項。

底部的 **Save settings** 與 **Start / Stop** 固定顯示。切換分頁會保留尚未儲存的選擇；開始時也會儲存設定。若要讓瀏覽器的下一次字幕使用新引擎，先按 Save settings，再從 Extension 開始收音。桌面收音進行中，需先停止才能更改語言或模型。

## 語氣與笑聲（4.5.0）

在「語音字幕」選擇「語氣與笑聲」，可關閉或選自然標記、ww、笑、草。桌面模式下次開始時套用；Mac 能在本機辨識明確笑聲，其他桌面系統依辨識出的文字標記處理。辨識不確定、來不及完成或電腦熱壓力升高時會略過聲音分析。詳見[功能與限制](speech-tone.md)。
## 日文接續字幕（4.5.1）

日文句尾被音訊切開時，桌面模式會檢查前一句，接回有明確文法關係的片段再翻譯。例如「魚が逃げて／しまいました」會合成「魚が逃げてしまいました」。新字幕會重帶必要的前句尾，讓完整意思可見；已顯示的歷史字幕保留。

明顯未說完的音訊最多延長四秒，總長不超過十二秒。這能減少斷在否定或助動詞前的誤譯，但這些句子的完整中文可能稍晚出現。「はい」「いいえ」等獨立短答不會因此固定多等四秒。

這項處理不能補回原本沒收到的聲音，也不能保證修正所有辨識錯字或省略語。更新擴充功能後，請重新載入原本開著的影片分頁，再開始收音，讓分頁使用最新的連線。

## 極短句與低延遲（4.5.2）

本機翻譯會直接處理少量意思明確的獨立短句，例如「本当に？」與問候、感謝，減少模型運算。自訂詞彙仍優先；「大丈夫」「やばい」等多義詞以及較長句子仍交給模型。

「明日は？」會保留成「明天呢？」。若只收到否定句尾「ません」，找不到可以可靠接回的前文時會顯示「不……」，不猜測省略的動詞。接續規則也新增部分口語與否定句尾，僅使用已收到的日文。

這版沒有新增收音等待，也不會每句多跑一次校正。直接回傳的短句更省運算；需要接回較長前文的句子仍有原本的辨識與翻譯耗時。實測範圍請見[4.5.2 記錄](retests/4.5.2.md)。
