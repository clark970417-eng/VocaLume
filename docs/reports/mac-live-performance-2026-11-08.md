## 測量範圍

Apple M5、16 GB、macOS 26.4.1、Electron 44.9.3、VocaLume 4.6.6。兩輪各用獨立的暫存設定，沿用同一份本機 Haas-ja Q8_0 和 HY-MT1.5 1.8B Q4_K_M。日翻繁中，收音間隔同為 800 ms，降噪、語音輸出、講者辨識與雲端模型關閉。

135.088 秒的固定音檔包含二十段不同的合成日語與固定的兩秒段間留白，錄音路徑同時插入十筆桌面文字翻譯。測試以 Web Audio 提供 MediaStream，經過正式的 VAD、桌面程序通訊、語音辨識、翻譯與字幕 DOM。字幕延遲由合成片段末尾至譯文進入字幕 DOM 估算。百分位採 nearest rank，這裡字幕的 p99 即最慢一筆。

測試視窗隱藏，計時器間隔只能反映程式排程延遲。這輪未量測實際畫面更新、物理麥克風、瀏覽器直播或 OBS。Electron CPU 取樣不含獨立 Haas 子程序，不能換算功耗。兩輪均為同一部 Mac 上的單次測試。

## 重現

用 `desktop-app/scripts/benchmark-mac-live.mjs` 執行。將第一個參數換成修改前或修改後的 `out/main/index.js`，兩輪使用同一 WAV 與 JSON。

```sh
cd desktop-app
JTL_BENCH_TEXT=1 node scripts/benchmark-mac-live.mjs BUILD_MAIN sustained.wav sustained.json report.json LABEL
```

這次的固定輸入和兩輪量測保存於本機 `/tmp/vocalume-mac-bench.nViBBQHq/`，檔名為 `sustained.wav`、`sustained.json`、`before-sustained.json` 和 `after-sustained.json`。音檔 SHA-256 為 `8237a45f8a22e564cc461f50b7b439570f43848164c7b68454a8ae9ba7435216`。修改前主程式 SHA-256 為 `6209044e942e44b53f14922c87cb577cb4ddab4eaa15a7a6ac375ba45e2f4bcc`，修改後為 `cf1fc3a392baa3e8746c07999076efec3784aaa3c5423d73933c58f172c9885b`。

初版曾在三筆重疊的短測中全部取消桌面文字翻譯。調整為只有正式字幕優先時才中斷背景工作，並在程式內有限度重試後，最終版在上表的較長測試完成了十筆。
