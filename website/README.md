# VocaLume website

Live website: https://vocalume.vercel.app/

The product site includes Traditional Chinese, Simplified Chinese, English, Japanese and Korean pages, responsive mobile layouts, caption/chat demonstrations, and installation instructions. It uses static HTML/CSS/JavaScript, with an optional Three.js hero decoration.

## Preview

From this folder, run `python3 -m http.server 4173 --directory dist` and open http://localhost:4173. The checked-in site does not require a build step.

## Update

- Edit each localized page in `dist/`; shared behavior is in `app.js` and `language.js`.
- Update the live-stream and chat preview translations in `dist/demo-posters.js`. The previews keep the Japanese source text. The Japanese page uses Traditional Chinese as the example translation target.
- Download pages are generated by `scripts/build-download-pages.py`. Checksums and tutorial media are maintained in `dist/`.
- To rebuild the optional decoration, run `npm install` followed by `npm run build`.
- Vercel serves `dist/` as configured in `vercel.json`. Credentials, deployment account settings and local environment files are excluded.

## Media and downloads

The stream excerpt retains source attribution and the non-affiliation notice. Browser/chat framing is a simulation, identified in the site. Videos are demonstration media, not standalone software assets. Installer downloads point to the verified GitHub Releases assets; repository and release links also point to GitHub. Model downloads and optional external API services require network access.


### Automatic website language

First home-page visits use /api/site-language: KR -> Korean; JP -> Japanese; TW/HK/MO -> Traditional Chinese; CN/SG -> Simplified Chinese; other countries -> English. Missing location/service failure falls back to browser language. Manual preferences take priority, including selecting the current language during a pending lookup. Explicit localized pages do not geolocate. The endpoint is private/no-store and returns no IP. Test with node --test tests/site-language.test.mjs.
